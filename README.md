This repository includes datasets that were used in the application library of IAM PARIS along with scripts for data processing.

Two datasets were used from external sources:

1. The data shown the Climate Data Platforms Inventory is sourced from the World Resources Institute webpage as follows: Friedrich, J., Roeyer, H., Lumley, S., Delmonte, D., & Siddhi, A. (2023). Overview of 100+ Climate Data Platforms. World Resources Institute, Climate Works Foundation. https://www.wri.org/data/overview-100-climate-data-platforms

2. The IAMC data is extracted from the website of the Integrated Assessment Modeling Consortium based on the scraping script included in the repo. The following pages have been scraped:
    - https://www.iamconsortium.org/resources/tools-visualization/
    - https://www.iamconsortium.org/resources/databases/
